# charity: water Push the Box Game

A themed puzzle game created for charity: water, where players push water buckets onto dry soil fields to bring clean water to barren lands.

## Game Objective

Push the water buckets (🪣) onto the dry soil fields (marked with dashed borders) to water them. Once all soil is watered, the fields bloom into flower fields and you advance to the next level.

## Features

- **5 Progressive Levels**: Increasing difficulty from simple pushes to complex navigation
- **Scoring System**: Earn points for watering soil, lose points for contaminated puddles
- **Responsive Design**: Works on both desktop and mobile devices
- **Keyboard & Touch Controls**: WASD/Arrow keys for desktop, on-screen D-pad for mobile
- **Reset Functionality**: Reset current level if buckets get stuck
- **Win Celebration**: Confetti effect when completing levels
- **Brand Integration**: Uses official charity: water color palette and styling

## Controls

### Desktop

- **WASD** or **Arrow Keys** to move

### Mobile

- **On-screen D-pad** buttons for movement

### General

- **Reset Button** to restart the current level

## Game Elements

- 🚰 **Player** (Jerry Can): You control this character
- 🪣 **Bucket**: Push these onto dry soil to water it
- 🌱 **Dry Soil**: Target areas that need watering
- 💧 **Watered Soil**: Successfully watered areas
- 🌸 **Flower Field**: Completed level areas
- 💧 **Contaminated Puddle**: Avoid these - they cost 10 points!

## Technical Implementation

- **HTML5/CSS3/JavaScript**: No external frameworks
- **BEM Methodology**: Clean, maintainable CSS architecture
- **Responsive Design**: Adapts to different screen sizes
- **Touch-Optimized**: Prevents double-tap zooming on mobile

## Scoring

- **+50 points** for watering each soil field
- **+100 points** for completing a level
- **-10 points** for stepping on contaminated puddles

## Browser Compatibility

Works in all modern browsers that support ES6+ features.
